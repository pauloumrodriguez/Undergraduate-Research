# Resultados dos modelos

Resultados exploratórios da v11 anual, com 100 repetições por ano-base de
2006 a 2010 em cada avaliação.

- [Teste de ligações ocultadas](roc_auc_v11_100_repeticoes/resumo.csv)
- [Ranking temporal Top 20](temporal_v11_100_repeticoes/ranking_top20_consolidado.csv)
- [Avaliação temporal por limiar](temporal_v11_100_repeticoes/limiares_consolidados.csv)

Os arquivos JSON de configuração registram os hashes das execuções locais
originais. A edição para GitHub tornou os caminhos e a validação portáteis.
Os hashes do código e da avaliação intermediária nessas configurações
identificam os arquivos da execução original. Os CSVs de entrada e os
resultados publicados preservam os bytes originais.
